# Screen

Минималистичное macOS-приложение на Go для вывода видео с HDMI-источника через USB-карту захвата. Использует AVFoundation и нативный интерфейс Cocoa без сторонних Go-зависимостей.

## Требования

- macOS 13 или новее.
- Go 1.26.5 или новее.
- Xcode Command Line Tools с `clang` и `codesign`.
- USB HDMI-capture устройство с поддержкой UVC.

## Сборка и запуск

```bash
make run
```

Команда собирает и подписывает `Screen.app`, после чего запускает его. Для сборки без запуска используй `make build`.

При первом запуске разреши Screen доступ к камере: macOS распознаёт UVC-карту захвата как камеру.

## Возможности

- Автоматический поиск внешних видеоустройств.
- Выбор источника, разрешения и формата видео.
- Автоматический выбор качества около 1080p.
- Обновление списка при подключении и отключении устройств.
- Полноэкранный режим: `Control + Command + F`.

## Ограничения

Подключение обычного HDMI-кабеля напрямую к Mac не поддерживается: нужен USB UVC-захват. Устройства с собственными драйверами и видео с HDCP-защитой могут не работать.

Screen только показывает изображение. Для управления клавиатурой и мышью подключённого компьютера потребуется отдельный USB HID-контроллер или KVM.
